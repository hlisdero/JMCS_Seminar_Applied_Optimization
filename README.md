# Seminar Applied Optimization

Presentation for the Seminar Applied Optimization for the Swiss Joint Master Program in Computer Science.

## Structure

- [ipopt-rs](./ipopt-rs/README.md): Demo with [ipopt](https://crates.io/crates/ipopt) crate to run Ipopt from Rust.
- [Presentation](./Presentation/Presentation.pdf): The slides used for the presentation in LaTeX.
  - bibliography: BibTex entries
  - images: Images used in the presentation
- [ripopt](./ripopt/README.md): Demo with [ripopt](https://crates.io/crates/ripopt) crate.
- [ripopt_benchmarks](./ripopt_benchmarks/): Results of running locally the benchmarks in [ripopt](https://crates.io/crates/ripopt) in May 2026.
